# Northstar V4

1. Unzip this package.
2. In your GitHub repository, upload/replace `index.html`, `manifest.json`, and `sw.js`, and add `icon.svg` in the repository root.
3. Commit the changes. Keep GitHub Pages enabled on `main` / root.
4. Open your GitHub Pages website in Safari. Refresh it, then use Share → Add to Home Screen if needed.

V4 includes the updated four-day aesthetic programme exactly as supplied and a redesigned 12-item bottom navigation that uses a fixed six-column grid across two rows, preventing labels such as Measurements and Spending from running into each other.

Data is stored locally in this browser using localStorage. Export a JSON backup regularly. Clearing Safari website data can erase it. Meal photos are stored locally; macros must be entered manually (photo recognition is not included). The workout logger uses the current weekday's gym workout; if you log a session on a different day, choose the appropriate weekday by changing the date/device day or log it on the workout day.
